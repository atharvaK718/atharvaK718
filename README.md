## 🚀 Featured Projects

### LexRAG — Intelligent Document Analysis Platform

> Enterprise-grade agentic AI platform for legal and financial document analysis built on a Supervisor Agent architecture

**Stack:** LangGraph · Qdrant · Elasticsearch · Neo4j · FastAPI · Python

- Architected a multi-stage hybrid retrieval pipeline fusing dense vector search (Qdrant), BM25 keyword search (Elasticsearch), and knowledge graph traversal (Neo4j) via **Reciprocal Rank Fusion (RRF)** and cross-encoder reranking — improving top-k retrieval relevance over single-method baselines
- Implemented a stateful agentic workflow (**Plan → Retrieve → Synthesize → Verify**) using LangGraph to enable autonomous multi-hop reasoning over complex documents, with automated evidence grounding to reduce hallucination risk
